# Установка и запуск CRYPTO_HACK (Unity 6.6)

Игра — симулятор хакера на русском языке: 8 миссий на Python, майнинг-ферма,
биржа с живым графиком, чёрный рынок апгрейдов, школа Python, файлы и профиль
с достижениями. Весь интерфейс собран из C#-кода (uGUI), префабы и сцены
настраивать не нужно.

Этот гайд рассчитан на человека, который Unity раньше не открывал: всё
описано клик за кликом. Если тебе нужно только «поставить и играть» —
читай разделы **1** и **2** по порядку, остальное пригодится позже.

**Проверено на:** Unity **6.6 (6000.6.3f1)**. Открывается также на других
сборках 6.6 (`6000.6.x`), на Unity 6.0–6.5 и на 2022.3 LTS — код не использует
новых API.

| Раздел | О чём |
|---|---|
| 1 | что установить (Unity, python — по желанию) |
| **2** | **полный путь: скачать ZIP → распаковать → открыть в Unity → играть** |
| 3 | управление в игре |
| 4 | настоящий Python или встроенный симулятор |
| 5 | собрать свою сборку (exe для Windows и т.п.) |
| 6 | проблемы и их решение |
| 7 | где лежат сохранения |
| 8 | что внутри проекта + проверка кода |
| 9 | лицензии |

## 1. Что нужно установить

| Что | Обязательно? | Зачем | Где взять |
|---|---|---|---|
| **Unity Hub** | да | менеджер проектов и версий Unity | <https://unity.com/download> |
| **Unity Editor 6.6** (`6000.6.3f1`) | да | сам движок, который запускает игру | ставится из Unity Hub, вкладка *Installs* |
| **python3** | нет | режим «настоящий Python»: код из редактора реально выполняется | <https://www.python.org/downloads/> |
| архиватор (7-Zip, WinRAR) | нет | Windows и macOS распаковывают ZIP сами | <https://7-zip.org/> |

Без python3 игра полностью работает — просто вместо реального выполнения кода
включается встроенный симулятор Python (раздел 4).

### 1.1. Ставим Unity Hub

1. Открой <https://unity.com/download>.
2. Скачай **Unity Hub** для своей ОС и установи как обычную программу.
3. Запусти Hub и создай бесплатный аккаунт Unity (Personal) — без входа
   редактор не запустится. Кнопка *Sign in* в правом верхнем углу.

### 1.2. Ставим редактор Unity 6.6

1. В Unity Hub открой вкладку **Installs** → кнопка **Install Editor**.
2. В списке найди **Unity 6.6** (внутри он называется `6000.6.x`).
   Справа у него есть выпадающий список версий-патчей: выбери **`6000.6.3f1`** —
   ровно ту же, что стоит у тебя, так проект откроется вообще без предупреждений.
   Любая другая из ветки `6000.6.x` тоже подойдёт.
3. Если 6.6 в списке нет — нажми **Install Editor → Archive** и найди её там
   или поставь 2022.3 LTS: проект открывается и в ней (см. раздел 6, пункт
   про версию проекта).
4. В окошке выбора модулей ничего дополнительно отмечать не нужно. Для сборки
   под Windows можно по желанию добавить *Windows Build Support (Mono)*, но
   для запуска в редакторе он не нужен.
5. Нажми **Install** и дождись окончания — это несколько ГБ и 5–20 минут.

Пока Unity скачивается, можно спокойно делать раздел 2.

### 1.3. Ставим python3 (необязательно)

* **Windows**: скачай установщик с <https://python.org>, при установке
  обязательно отметь галочку **Add python.exe to PATH**.
* **Linux**: `sudo apt install python3` (в большинстве систем уже стоит).
* **macOS**: `brew install python3` или официальный установщик.

Проверка — открой терминал (`cmd` или PowerShell в Windows) и введи:

```bash
python3 --version     # Linux/macOS
py -3 --version       # Windows
```

Если видишь `Python 3.x.x` — всё хорошо. Игра ищет интерпретатор сама.

## 2. Полный гайд: от ZIP-архива до запущенной игры

Это самый простой путь. Он состоит из шести шагов: **скачать → распаковать →
проверить → открыть в Unity Hub → дождаться импорта → нажать Play.**

### 2.1. Шаг 1. Скачиваем архив

**Способ A — сразу файл проекта (рекомендую).**

Открой эту ссылку в браузере:

> **<https://github.com/ckot23/CRYPTO_HACK.io/raw/arena/01a0cc25-crypto-hack-io/CRYPTO_HACK_unity.zip>**

Браузер сразу скачает файл **`CRYPTO_HACK_unity.zip`** (примерно 530 КБ).
Никуда заходить на GitHub не нужно — это прямая ссылка на файл.

**Способ B — если ты уже на странице репозитория.**

1. Открой <https://github.com/ckot23/CRYPTO_HACK.io>.
2. Сверху есть выпадающий список веток (**main** ▾) — переключись на
   **`arena/01a0cc25-crypto-hack-io`**. Именно в этой ветке лежит Unity-версия.
3. В списке файлов найди **`CRYPTO_HACK_unity.zip`** и нажми на него, затем
   кнопку с иконкой загрузки (**Download raw file**) справа сверху.
4. Если вместо файла скачался весь репозиторий (`CRYPTO_HACK.io-arena-….zip`) —
   тоже не беда: распакуй его, внутри будет `CRYPTO_HACK_unity.zip`, работай
   дальше с ним.

> Не пользуйся кнопкой **Code → Download ZIP**, если не хочешь лишних шагов:
> она отдаёт архив всего репозитория, а не проекта. Файл проекта называется
> ровно `CRYPTO_HACK_unity.zip`.

Файл обычно оказывается в папке **Загрузки / Downloads**.

### 2.2. Шаг 2. Распаковываем архив

> ⚠️ **Главная ошибка новичка:** открыть ZIP-файл двойным кликом и запустить
> игру прямо «изнутри архива». Так нельзя — Unity видит только обычные папки.
> Архив нужно именно **распаковать** на диск.

**Windows (встроенными средствами, без программ):**

1. Открой папку **Загрузки** в проводнике.
2. Правый клик по `CRYPTO_HACK_unity.zip` → **Извлечь всё…**
   (в Windows 11: правый клик → *Показать дополнительные параметры* →
   *Извлечь всё…*, либо иконка «Извлечь всё» вверху окна).
3. В поле «Куда извлечь» впиши путь, например `C:\Games\CRYPTO_HACK_unity`,
   и нажми **Извлечь**.
4. Открой получившуюся папку — внутри должны лежать `Assets`, `Packages`,
   `ProjectSettings`, `README.md`, `INSTALL.md` (см. проверку в 2.3).

7-Zip / WinRAR: правый клик по архиву → *7-Zip → Распаковать в
"CRYPTO_HACK_unity\"* (или *Извлечь в текущую папку*).

**macOS:** двойной клик по `CRYPTO_HACK_unity.zip` — рядом появится папка
`CRYPTO_HACK_unity`. Если macOS положила её в *Загрузки*, лучше перенести в
`~/Documents/Unity`.

**Linux:** правый клик → *Extract Here*, либо в терминале:

```bash
mkdir -p ~/games/CRYPTO_HACK_unity
unzip ~/Downloads/CRYPTO_HACK_unity.zip -d ~/games/CRYPTO_HACK_unity
```

**Куда распаковывать — требования к пути (важно):**

* путь **без русских букв** (кириллица ломает Unity и Python);
* путь **без пробелов** — используй `_` вместо пробела;
* путь **не на съёмном диске и не в облачной папке** (OneDrive/iCloud/Google
  Drive могут блокировать файлы во время импорта);
* для Windows лучше что-то вроде `C:\Games\CRYPTO_HACK_unity`, для Linux/macOS —
  `~/games/CRYPTO_HACK_unity`.

### 2.3. Шаг 3. Проверяем, что распаковалось правильно

Открой папку, которую ты получил. Уровнем ниже (`CRYPTO_HACK_unity`) должно
быть **ровно это**:

```
CRYPTO_HACK_unity/
├── Assets/              ← вся игра: скрипты, контент, шрифты
├── Packages/
│   └── manifest.json    ← список зависимостей (Unity UI 2.6.0, Input System)
├── ProjectSettings/
│   └── ProjectVersion.txt   ← здесь написано: m_EditorVersion: 6000.6.3f1
├── tools/
│   └── check_cs.py      ← линтер кода (не обязателен для игры)
├── README.md            ← краткое описание игры
├── INSTALL.md           ← этот гайд
└── .gitignore
```

Быстрая проверка «всё ли на месте» — загляни внутрь:

* `Assets/Scripts/GameBoot.cs` — есть?
* `Assets/Resources/gamedata.json` — есть? (это весь контент игры)
* `Assets/Resources/Fonts/` — три файла `.ttf` и две лицензии?

Если чего-то нет — скорее всего распаковка не дозавершилась (архиватор спросил
про замену файлов и ты нажал «Пропустить») или ты распаковал только часть.
Удали папку и распакуй архив заново.

> **Запомни этот путь** — дальше в Unity Hub нужно будет выбрать именно папку
> `CRYPTO_HACK_unity` (ту, внутри которой `Assets`), а не файл `.zip`.

### 2.4. Шаг 4. Открываем проект в Unity Hub

1. Запусти **Unity Hub**.
2. Вкладка **Projects** (слева). Если список пустой — это нормально.
3. Нажми кнопку **Add** → в выпадающем меню **Add project from disk**
   (в старых версиях Hub кнопка называется *Open* → *Open project from disk*).
4. В окне выбора файлов **зайди в папку** `CRYPTO_HACK_unity` и нажми
   **Выбрать папку / Select Folder**. Файл внутри выбирать не нужно —
   Unity ищет проект по папке, в которой лежат `Assets` и `ProjectSettings`.
5. В списке проектов появится карточка **CRYPTO_HACK_unity**. Рядом будет
   подпись версии: **`6000.6.3f1`** — именно она стоит в проекте, так что
   никаких диалогов про смену версии не будет.
   Если у тебя установлена другая сборка 6.6 (например `6000.6.2f1`), Hub
   напишет «missing» или предложит открыть своей версией — выбирай свою,
   диалог подтверждаем. Убрать предупреждение насовсем можно, вписав свою
   версию в `ProjectSettings/ProjectVersion.txt` (это обычный текстовый файл).
6. Нажми на название проекта (или кнопку **Open**) — Unity начнёт открывать
   проект.

**Если Unity Hub не видит папку или ругается «не является проектом Unity»** —
почти всегда одна из трёх причин: выбрана папка на уровень выше/ниже, чем
нужно (выбирать надо ту, где `Assets`), выбрана не распакованная папка внутри
ZIP, либо распаковка не завершилась. Вернись к 2.3 и проверь структуру.

### 2.5. Шаг 5. Первый импорт: чего ждать

Это самый долгий этап — Unity создаёт папку `Library` со служебными файлами.

1. Появится окно загрузки проекта, потом откроется редактор (тёмный интерфейс).
   Первый раз это 2–10 минут. Пока в правом нижнем углу крутится полоска
   прогресса — **ничего не нажимай**.
2. Внизу мигнёт «Compiling…» / «Importing…» — это нормально.
3. Unity может показать диалоги:
   * **«Install packages» / сообщение о недостающих пакетах** (Unity UI,
     Input System) — соглашайся, они нужны игрушке;
   * **«Enable the new input backends and restart?»** — можно ответить как
     угодно: игра работает и с новым Input System, и со старым Input Manager;
   * **«Enter Safe Mode?»** — если такое окно появилось, значит в консоли есть
     ошибки компиляции: нажми *Ignore* и посмотри раздел 6 этой инструкции.
4. Когда редактор откроется целиком — посмотри окно **Console**
   (меню **Window → General → Console** или сочетание Ctrl+Shift+C).
   На чистом проекте там пусто или только обычные серые сообщения. Красных
   ошибок быть не должно.

### 2.6. Шаг 6. Запускаем игру

1. Вверху по центру — большая кнопка **▶** (*Play*). Нажми её.
2. Кнопка станет синей, редактор переключится в режим игры. Появится неоновый
   экран с «матричным дождём» и надписью **CRYPTO_HACK**.
3. Нажми **НАЧАТЬ ИГРУ** → пойдёт «загрузка BIOS» (можно пропустить пробелом)
   → откроется рабочий стол NeonOS с иконками программ слева.
4. Играй! Остановить игру — снова кнопка **▶** (или Ctrl+P).

**Почему не нужна сцена.** Обычно Unity-проект требует сцену с объектами; здесь
игра стартует сама из любой сцены (в проекте используется
`[RuntimeInitializeOnLoadMethod]` в `Assets/Scripts/GameBoot.cs`). Поэтому:

* если видишь пустую сцену с именем *Untitled* — это правильно, просто жми
  **▶ Play**;
* сохранять или создавать сцену не нужно;
* для сборки отдельного приложения сцену всё-таки надо создать — это делает
  пункт меню **CRYPTO_HACK → Создать сцену и добавить в сборку** (раздел 5).

**Чек-лист «игра запустилась правильно»:**

* ✅ виден неоновый экран с заголовком CRYPTO_HACK и кнопкой НАЧАТЬ ИГРУ;
* ✅ курсор превращается в руку над кнопками (клики работают);
* ✅ после загрузки BIOS открывается рабочий стол, сверху видны курсы монет
  (₿ BTC, Ξ ETH, ɱ XMR, ◎ SOL) и счётчик `$`;
* ✅ слева иконки-программы: ⌁ Хак-терминал, ⚙ Майнеры, ▲ Биржа, ✚ Апгрейды,
  ✎ Школа Python, ▶ Файлы, ★ Профиль;
* ✅ в Хак-терминале открывается первая миссия, в редакторе видна заготовка
  кода, после нажатия **▶ ЗАПУСТИТЬ** в консоли бегут строчки.

Если что-то из этого не так — смотри раздел 6.

### 2.7. Если хочется без предупреждений о версии

Если ты открываешь проект другой сборкой Unity, Hub каждый раз может
спрашивать про смену версии. Чтобы этого не было, впиши свою версию в файл
`ProjectSettings/ProjectVersion.txt` — он открывается любым блокнотом:

```
m_EditorVersion: 6000.6.2f1
```

Свою версию смотри в Unity Hub → вкладка *Installs* (например `6000.6.2f1`).
Это единственное, что там написано; правка безопасна и обратима.

## 2B. Вариант «закинуть игру в уже существующий Unity-проект»

Если у тебя есть свой проект Unity и ты не хочешь открывать архив отдельно,
игру можно перенести внутрь него копированием файлов.

1. **Скопируй код:** из архива возьми папку `Assets/Scripts` целиком и
   положи в свой проект (получится `ТвойПроект/Assets/Scripts/…`).
2. **Скопируй контент и шрифты:** папку `Assets/Resources` из архива — в свой
   проект. Она объединится с твоей: добавятся `gamedata.json` и `Fonts/`
   (не перезаписывай свои файлы с такими же именами, если они есть).
3. **Скопируй редакторное меню (необязательно):** `Assets/Editor/CryptoHackMenu.cs`.
4. **Допиши зависимости** в свой `Packages/manifest.json` (в блок
   `"dependencies"`):

   ```json
   "com.unity.ugui": "2.6.0",
   "com.unity.inputsystem": "1.19.0",
   ```

   Номер `com.unity.ugui` должен совпадать с минорной версией редактора
   (см. таблицу в разделе 6). Unity UI почти наверняка уже стоит; Input System
   нужен только если у тебя Active Input Handling = «Input System (New)».
5. **Правь `gamedata.json` при желании** — это весь контент игры (миссии,
   уроки, апгрейды, цитаты).
6. **Запуск:** игра стартует сама при нажатии Play (из-за
   `[RuntimeInitializeOnLoadMethod]` в `GameBoot.cs`). Если тебе это мешает в
   своём проекте — удали этот атрибут и метод `Bootstrap()` из `GameBoot.cs`,
   а затем создавай игру вручную: правый клик в *Hierarchy* → **Create Empty**
   → назови `CRYPTO_HACK` → **Add Component** → `GameBoot` → Play.

Конфликтов с твоим проектом почти не будет: всё лежит в отдельном namespace
`CryptoHack`, интерфейс рисуется на своей Canvas в режиме *Screen Space
Overlay*, никакие настройки проекта и сцены не меняются. Исключение — если у
тебя в проекте уже есть класс `Fmt`, `Game` или `Theme` в глобальном
namespace: тогда переименуй свой или наш (мы обращаемся к своим через
namespace).

## 3. Управление в игре

| Действие | Как |
|---|---|
| Открыть программу | клик по иконке слева (⌁ терминал, ⚙ майнеры, ▲ биржа, ✚ апгрейды, ✎ школа, ▶ файлы, ★ профиль) |
| Быстрое открытие программ | клавиши **1 … 7** |
| Закрыть окно | **✗** в шапке окна или кнопка на панели задач; **Esc** закрывает верхнее окно |
| Перетащить окно | потянуть за шапку окна |
| Меню системы | **⌁ GHOST** в левом нижнем углу (звук, обучение, сброс прогресса, выход в главное меню) |
| Запустить код в терминале | кнопка **▶ ЗАПУСТИТЬ** или **Ctrl+Enter** |
| Отступ в редакторе кода | **Tab** (4 пробела); переключение режима — кнопка **РЕЖИМ: PYTHON / СИМУЛЯТОР** |
| Пропустить загрузку BIOS | **пробел** или любая клавиша |
| Сделка на бирже | ввести сумму и нажать **ПРОДАТЬ / КУПИТЬ**; **Enter** в поле подставляет максимум |

Редактор кода — свой, с подсветкой синтаксиса и кареткой: кликай по строке,
печатай текст; Backspace/Delete/стрелки/Home/End работают как в обычном
редакторе. Строка состояния снизу справа подсказывает про ошибки синтаксиса.

Про ввод: игра не использует `EventSystem`, `Button` и `InputField` — клики
разбирает свой роутер (`Assets/Scripts/UI/Ui.cs`), а мышь и клавиатуру читает
`Assets/Scripts/UI/UiInput.cs`, который сам выбирает доступный стек ввода
(новый Input System или старый Input Manager). Поэтому настройка **Active
Input Handling** может стоять в любом положении, а расставлять «модули ввода»
на сцене не нужно — сцены с объектами в игре нет.

## 4. Настоящий Python или встроенный симулятор

В шапке хак-терминала есть кнопка режима, а сверху на рабочем столе — индикатор
`PY: …`.

* **PYTHON** — код запускается настоящим `python3` в отдельном процессе
  (`Assets/Scripts/Core/PyRunner.cs`). Игра подкладывает в скрипт заглушки
  функций `scan()`, `connect()`, `brute()`, `bypass()`, `decrypt()`,
  `extract()`, `drain()`, `install_miner()`, `wallets()` — они печатают
  результат в терминал. Ограничение по времени 8 секунд, вывод построчный.
* **СИМУЛЯТОР** — тот же сценарий, но целиком внутри игры
  (`Assets/Scripts/Core/PySim.cs`): проверяются обязательные конструкции
  миссии, печатается правдоподобный лог, считается стиль кода.

Если Python не найден, кнопка режима гаснет и включается симулятор. Порядок
поиска: `py -3`, `python`, `python3` (Windows) и `python3`, `python`
(Linux/macOS). Пробный запуск игра делает при старте, так что индикатор режима
появляется сразу. Python установлен, но не находится? Проверь в терминале
`python3 --version`; если команда работает, а игра нет — перезапусти Unity,
она читает PATH на момент старта.

## 5. Собрать свою сборку (exe для Windows и т.п.)

Игра стартует без сцены, но **сборке сцена нужна**. Делается в два шага:

1. В Unity: меню **CRYPTO_HACK → Создать сцену и добавить в сборку**.
   Скрипт создаст `Assets/Scenes/Game.unity` и добавит её в список сцен сборки.
2. **File → Build Profiles** (в Unity 6.6 меню называется так; в 2022.3 —
   *File → Build Settings…*): выбери платформу (Windows/macOS/Linux), при
   необходимости **Switch Platform**, затем **Build** и укажи пустую папку
   (например, `Build`).

Готовый билд запускается как обычная программа. Сохранения у билда и у
редактора общие (раздел 7), так что прогресс не потеряется.

## 6. Проблемы и их решение

**Unity Hub не видит проект / «не является проектом Unity»**
Выбрана не та папка. Нужна та, внутри которой лежат `Assets` и
`ProjectSettings` (шаг 2.3). Архив при этом должен быть уже распакован.

**`The type or namespace name 'UI' does not exist in the namespace 'UnityEngine'`**
Не установлен пакет Unity UI. **Window → Package Manager → Unity Registry** →
**Unity UI** (`com.unity.ugui`) → **Install**. Либо поправь
`Packages/manifest.json` руками и перезапусти Unity — номер пакета совпадает с
минорной версией редактора:

| Твоя версия Unity | Строка в `manifest.json` |
|---|---|
| Unity 6.6 (`6000.6`) | `"com.unity.ugui": "2.6.0"` |
| Unity 6.3 (`6000.3`) | `"com.unity.ugui": "2.3.0"` |
| Unity 6.0 (`6000.0`) | `"com.unity.ugui": "2.0.0"` |
| Unity 2022.3 LTS | `"com.unity.ugui": "1.0.0"` |

**Package Manager пишет `Package [com.unity.ugui@…] cannot be found / cannot be resolved`**
В манифесте номер пакета от другой версии Unity. Лечится меню
**Help → Reset Packages to defaults** (Unity сама прописывает верные номера)
либо таблицей выше. После правки `manifest.json` перезапусти Unity.

**Открылось окно «Enter Safe Mode?»**
Значит, есть ошибки компиляции. Нажми *Ignore*, открой **Console**
(Ctrl+Shift+C) и посмотри первую красную строку — обычно это либо
недостающий пакет (см. выше), либо сообщение о том, что не найден какой-то
файл проекта (пере-распакуй архив, шаг 2.2–2.3).

**Клики и клавиатура не реагируют, в консоли `InvalidOperationException: You are
trying to read Input using the UnityEngine.Input class…`**
В Player Settings выбрана схема ввода, которой нет в проекте. **Edit → Project
Settings → Player → Other Settings → Active Input Handling** → поставь
**Input Manager (Old)** или **Both**, затем перезапусти Unity. Игра сообщает
об этой же проблеме тостом в углу экрана при старте.

**Консоль: `The type or namespace name 'InputSystem' ... does not exist`**
Не установлен пакет **Input System** (`com.unity.inputsystem`): Window →
Package Manager → Unity Registry → **Input System** → Install. Либо удали эту
строку из `Packages/manifest.json` и выставь Active Input Handling =
*Input Manager (Old)*.

**Пустая сцена и ничего не появляется после нажатия Play**
Не сработал автозапуск. Проверь, что в проекте есть
`Assets/Scripts/GameBoot.cs` и в консоли нет ошибок компиляции. Запасной
вариант: в *Hierarchy* правый клик → **Create Empty** → в *Inspector* →
**Add Component** → `GameBoot` → Play.

**Нет звука**
Звук синтезируется кодом, аудиофайлов в проекте нет. Проверь: в игре меню
**⌁ GHOST → Звук: ВКЛ**; в Windows выбрано правильное устройство вывода.
На пустой сцене игра сама добавляет `AudioListener` — ничего настраивать не надо.

**Кракозябры вместо русских букв**
Не хватает шрифтов. Они лежат в `Assets/Resources/Fonts`
(`DejaVuSansMono.ttf`, `DejaVuSansMono-Bold.ttf`, `JetBrainsMono-LatinExt.ttf`).
Восстанови файлы с теми же именами. Символ ₿ есть только в JetBrains, поэтому
заменять его другим шрифтом нельзя.

**Кнопка РЕЖИМ в терминале не переключается**
`python3` не найден — игра работает в режиме симулятора. Это не ошибка, см.
раздел 4.

**В режиме PYTHON в консоли: «python не найден»**
Python установлен, но не прописан в PATH, либо Unity запущена до установки
Python (PATH читается на старте). Перезапусти Unity, при необходимости
переустанови Python с галочкой *Add python.exe to PATH*.

**Unity скачивает пакеты и пишет ошибки сети**
Первый импорт требует интернета (нужны пакеты Unity UI и Input System).
Проверь соединение/прокси; если пакеты уже в кэше, проект откроется и офлайн.

**Ошибка вида `Could not find a part of the path …` при открытии**
Путь к проекту содержит кириллицу, пробелы или находится в облачной папке
(OneDrive, iCloud). Перенеси папку в простой путь, например
`C:\Games\CRYPTO_HACK_unity`, и открой заново.

**`Unity says the project version is different (6000.6.3f1)`**
Проект помечен как Unity 6.6. Если у тебя другая сборка 6.6 или 2022.3 LTS —
соглашайся открыть своей версией, код совместим. Убрать предупреждение:
впиши свою версию в `ProjectSettings/ProjectVersion.txt` (шаг 2.7).

## 7. Где лежат сохранения

Прогресс пишется в JSON-файл `cryptohack_save.json` в папке
`Application.persistentDataPath`:

| ОС | Путь |
|---|---|
| Windows | `C:\Users\<имя>\AppData\LocalLow\<компания>\<продукт>\` |
| Linux | `~/.config/unity3d/<компания>/<продукт>/` |
| macOS | `~/Library/Application Support/<компания>/<продукт>/` |

`<компания>` и `<продукт>` берутся из *Edit → Project Settings → Player*;
у проекта это `DefaultCompany` / имя проекта. Скопируй файл — получишь бэкап.
Удали его или нажми **⌁ GHOST → Сбросить прогресс** — игра начнётся заново.
Рядом игра создаёт служебную папку `py_run/` — там лежат временные файлы для
настоящего Python.

## 8. Что внутри проекта и как проверить код

```
Assets/
  Editor/CryptoHackMenu.cs        пункт меню CRYPTO_HACK (создать сцену для сборки)

  Resources/Fonts/                шрифты + их лицензии
  Scripts/GameBoot.cs             точка входа: тема, звук, ввод, экраны
  Scripts/Core/Data.cs            DTO под gamedata.json
  Scripts/Core/Models.cs          модели + формат чисел (Fmt)
  Scripts/Core/Game.cs            состояние игры, экономика, майнинг, биржа, сохранения
  Scripts/Core/PySim.cs           встроенный симулятор Python
  Scripts/Core/PyRunner.cs        запуск настоящего python3
  Scripts/Core/Sfx.cs             синтез звуков (без аудиофайлов)
  Scripts/UI/Theme.cs             палитра, шрифты, метрики
  Scripts/UI/Ui.cs                фабрика узлов uGUI + свой роутер кликов
  Scripts/UI/UiInput.cs           ввод под старый Input Manager и новый Input System
  Scripts/UI/Widgets.cs           кнопка, скролл, прогресс, график, модалка, тосты
  Scripts/UI/UiWindow.cs          перетаскиваемое окно
  Scripts/UI/CodeEditor.cs        редактор Python с подсветкой + поле ввода + консоль
  Scripts/UI/Backgrounds.cs       сетка, «матричный дождь», луч сканирования
  Scripts/UI/Screens/             главное меню, BIOS-загрузка, рабочий стол
  Scripts/UI/Windows/             окна: терминал, майнеры, биржа, апгрейды, школа, файлы, профиль

ProjectSettings/ProjectVersion.txt  версия редактора проекта (6000.6.3f1)
tools/check_cs.py                 проверка кода без Unity
README.md, INSTALL.md             описание игры и этот гайд
```

**Проверка кода без Unity** — пригодится, если будешь править скрипты
блокнотом или VS Code:

```bash
pip install tree-sitter tree-sitter-c-sharp
python3 tools/check_cs.py Assets
```

Скрипт проверяет синтаксис всех `.cs`, обращения к членам собственных классов,
число аргументов в вызовах и объявленность полей. На этой версии проекта
вывод такой: `файлов 25, ошибок синтаксиса 0, семантических замечаний 0`.
(На системном Python с защитой PEP 668 может понадобиться
`pip install --break-system-packages …` или виртуальное окружение.)
