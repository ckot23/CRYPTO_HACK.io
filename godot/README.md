# CRYPTO_HACK — версия на Godot 4

Это перенос веб-игры из корня репозитория (React + TypeScript + Vite) на движок **Godot 4**.
Геймплей, контент и внешний вид повторяют веб-версию: 8 миссий-взломов на Python,
майнинг-ферма, биржа с живым графиком, магазин апгрейдов, школа Python, файловый
менеджер, профиль с достижениями.

Подробный разбор «что и как переносилось» — в **[docs/PORTING_GUIDE.md](docs/PORTING_GUIDE.md)**.

---

## Быстрый старт (2 минуты)

1. Скачай **Godot 4.3 или новее** (подойдёт и 4.4 / 4.5): https://godotengine.org/download
   Это один исполняемый файл, установка не нужна.
2. Запусти Godot → **Import** → укажи файл `godot/project.godot` из этого репозитория → **Import & Edit**.
3. Первый импорт занимает 5–15 секунд (импортируются шрифты и JSON с данными).
4. Нажми **F5** (или ▶ в правом верхнем углу). Игра начнётся с главного меню.

> Если Godot ругается на версию проекта — открой `Project → Project Settings` и просто
> сохрани проект (кнопка Save), набор фич обновится под твою версию.

## Сохранения

Файл `user://cryptohack_save_v1.json`:

* Windows: `%APPDATA%\Godot\app_userdata\CRYPTO_HACK\cryptohack_save_v1.json`
* Linux: `~/.local/share/godot/app_userdata/CRYPTO_HACK/cryptohack_save_v1.json`
* macOS: `~/Library/Application Support/Godot/app_userdata/CRYPTO_HACK/`

Сбросить прогресс можно в меню «GHOST» (левая нижняя кнопка) → «Сбросить прогресс».

## Режимы выполнения кода в миссиях

В окне «Хак-терминал» справа над редактором есть переключатель режима:

* **PYTHON** — код запускается настоящим интерпретатором (`python3` / `python` / `py -3`).
  Игры-функции (`scan()`, `connect()`, `brute()`…) подставляются «заглушками», поэтому
  твой код реально выполняется, а вывод и ошибки (`SyntaxError`, `NameError`) видны в консоли.
  Если код зациклится, он будет убит через 5 секунд.
* **СИМУЛЯТОР** — вывод терминала генерируется движком игры (как в веб-версии).
  Работает всегда, даже без Python.

Миссия считается выполненной, когда код удовлетворяет требованиям миссии
(проверяются те же регулярные выражения, что и в веб-версии — список лежит в `gamedata.json`).

## Экспорт в Windows/Linux

`Project → Export…` → Add… → Windows Desktop → Export Project.
Понадобится шаблон экспорта (`Manage Export Templates → Download`).

Готовый `.exe` будет лежать в выбранной папке; файл `gamedata.json` и шрифты
упаковываются внутрь `.pck`, так что рядом ничего докладывать не нужно.

## Частые вопросы

**Text в интерфейсе превратился в квадратики?**
Шрифты нарезаны на сабсеты (latin / cyrillic / latin-ext / greek), и в `neon.gd`
они связаны цепочкой fallback. Если правишь шрифты — проверь, что глиф есть
хотя бы в одном файле из цепочки (см. раздел «Шрифты» в гайде).

**«Python не найден» — это нормально?**
Да. Игра сама переключится на симулятор. Чтобы включить реальный Python, установи
Python 3 и добавь его в `PATH`, затем перезапусти игру.

**Пишет «Trying to assign an array of type Array to a variable of type Array[Font]»?**
Значит, где-то в `_chain()` потерялся типизированный массив — смотри `neon.gd`.

Больше подводных камней — в [docs/PORTING_GUIDE.md](docs/PORTING_GUIDE.md),
раздел «Подводные камни».
