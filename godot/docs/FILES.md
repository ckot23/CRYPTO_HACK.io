# Манифест: что переносить в Godot

Коротко: **папка `godot/` — это уже целый проект Godot.** Отдельно «собирать файлы для
переноса» не нужно: переносится либо вся папка целиком, либо отдельные подпапки
в существующий проект (см. Путь Б).

Всего: **53 файла**, ~1.4 МБ (из них 1.1 МБ — шрифты).

---

## Путь А. Импортировать как готовый проект (рекомендуется)

1. Открой Godot 4.3+ → **Import** → укажи `godot/project.godot` → **Import & Edit**.
2. Godot сам создаст служебные папки (`.godot/`, `*.import`) и импортирует шрифты —
   это займёт 5–15 секунд.
3. **F5** — игра запустится с главного меню.

Как забрать файлы на свой компьютер (любой способ):

* `git clone` репозитория и переход на ветку с файлами;
* GitHub → кнопка **Code → Download ZIP** → распаковать → папка `godot/` внутри;
* или скопировать папку `godot/` вручную, если файлы уже лежат локально.

Ничего доустанавливать не нужно: все шрифты и данные контента вложены внутрь.

## Путь Б. Перенести в свой существующий Godot-проект

### 1. Скопировать папки

```
godot/scenes/          →  <ТвойПроект>/scenes/
godot/scripts/         →  <ТвойПроект>/scripts/
godot/assets/          →  <ТвойПроект>/assets/
godot/icon.svg         →  <ТвойПроект>/icon.svg         (можно заменить своей иконкой)
```

> **Структура важнее, чем кажется.** Внутри кода есть жёсткие пути (`res://scripts/ui/…`
> в менеджере окон `desktop.gd`, `res://assets/data/gamedata.json` в загрузчике данных).
> Если разложить файлы по другим папкам — их придётся править. Скопируй как есть.

`project.godot` **не копируй поверх своего** — файл целиком заменит настройки твоего проекта.
Вместо этого открой свой `project.godot` как текст и внеси блоки ниже.

### 2. Прописать настройки в своём project.godot

```ini
[application]

config/name="CRYPTO_HACK"
run/main_scene="res://scenes/main_menu.tscn"
config/icon="res://icon.svg"

[autoload]

Game="*res://scripts/autoload/game.gd"
Sfx="*res://scripts/autoload/sfx.gd"

[display]

window/size/viewport_width=1280
window/size/viewport_height=720
window/stretch/mode="canvas_items"
window/stretch/aspect="expand"

[rendering]

renderer/rendering_method="gl_compatibility"
renderer/rendering_method.mobile="gl_compatibility"
environment/defaults/default_clear_color=Color(0.015686275, 0.02745098, 0.05882353, 1)
```

То же самое можно сделать мышкой:
**Project → Project Settings → Globals (Autoload)** — добавь два автозагружаемых скрипта
`Game` и `Sfx` (именно с такими именами, со включённым флагом «Enable» / звёздочкой);
**Project Settings → Application → Run → Main Scene** — `res://scenes/main_menu.tscn`.

### 3. Порядок первого запуска

1. Импорт шрифтов произойдёт автоматически; если в логе мелькают ошибки импорта —
   **Project → Reload Current Project**.
2. Запусти **F5**. Первый экран — главное меню, дальше «НАЧАТЬ ИГРУ» → BIOS → рабочий стол.

## Чего копировать НЕ надо

| Файл/папка | Почему |
| --- | --- |
| `.godot/` | Служебный кэш движка: импортированные ресурсы, кэш скриптов. Создаётся сам, у каждого свой. Уже в `.gitignore`. |
| `*.import` (например, `JetBrainsMono-Regular.ttf.import`) | Настройки импорта, генерируются Godot при первом открытии проекта. |
| `godot/README.md`, `godot/docs/*.md` | Документация для человека. Движку не нужны, но полезны — можешь держать рядом с проектом. |
| `godot/build/`, `godot/export/` | Сюда кладутся готовые `.exe` после экспорта; в репозитории их нет. |

`fallbacks` в `scripts/core/neon.gd`. Мерджить обратно в один файл не нужно.

## Чек-лист переноса

- [ ] `scenes/`, `scripts/`, `assets/`, `icon.svg` лежат в корне проекта (структура сохранена).
- [ ] В `project.godot` прописаны `run/main_scene` и два Autoload: `Game`, `Sfx`.
- [ ] Main Scene = `res://scenes/main_menu.tscn`.
- [ ] При первом запуске нет ошибок вида `Parse Error` и `Failed to load resource`.
- [ ] Меню → «НАЧАТЬ ИГРУ» → BIOS → рабочий стол, топбар показывает `$150`.
- [ ] Прогресс сохраняется: `user://cryptohack_save_v1.json` (см. меню «GHOST» → сброс сейва).

Если что-то из чек-листа не сработало — смотри раздел «Подводные камни» в
`PORTING_GUIDE.md` и «Частые вопросы» в `README.md`.
