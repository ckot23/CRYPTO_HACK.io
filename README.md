# CRYPTO_HACK — Godot-версия

В репозитории лежит **готовый проект игры для Godot 4** в одном архиве:

📦 **[CRYPTO_HACK_godot.zip](CRYPTO_HACK_godot.zip)** — 689 КБ, 54 файла, всё внутри
(скрипты, сцены, шрифты, данные миссий, инструкция и документация).

Ниже — как его распаковать и запустить в Godot. Занимает 5 минут, ничего собирать и
устанавливать (кроме самого Godot) не нужно.

---

## Шаг 1. Скачать архив

Любой способ на выбор:

* **С GitHub:** нажми на `CRYPTO_HACK_godot.zip` выше → кнопка со стрелкой вниз **Download**.
* **Прямая ссылка:**
  `https://github.com/ckot23/CRYPTO_HACK.io/raw/arena/01a0cc25-crypto-hack-io/CRYPTO_HACK_godot.zip`
* **Через git:**
  ```bash
  git clone --branch arena/01a0cc25-crypto-hack-io https://github.com/ckot23/CRYPTO_HACK.io.git
  ```
  Архив будет в корне склонированной папки.

> «Code → Download ZIP» тоже сработает, но тогда ты получишь архив с архивом внутри —
> придётся распаковывать дважды.

## Шаг 2. Скачать Godot

Нужен **Godot 4.3 или новее** — [godotengine.org/download](https://godotengine.org/download).

Устанавливать не нужно: это один исполняемый файл.

* Windows — `Godot_v4.x-stable_win64.exe`
* Linux — `Godot_v4.x-stable_linux.x86_64` (не забудь `chmod +x`)

## Шаг 3. Распаковать архив

Распакуй `CRYPTO_HACK_godot.zip` в папку **без пробелов и русских букв**, например:

```
C:\Games\CRYPTO_HACK\
└── CRYPTO_HACK_godot\
    ├── project.godot        ← главный файл проекта
    ├── icon.svg
    ├── INSTALL.txt
    ├── README.md            ← инструкция на запуск/управление/экспорт
    ├── scenes\              ← 3 сцены: главное меню → BIOS → рабочий стол
    ├── scripts\             ← 27 скриптов GDScript
    ├── assets\data\gamedata.json   ← все миссии, уроки, монеты, апгрейды
    ├── assets\fonts\        ← шрифты (вшиты в архив, интернет не нужен)
    └── docs\                ← гайды по переносу и манифест файлов
```

**Структуру внутри папки не меняй.** В коде прописаны пути вида
`res://scripts/ui/...` и `res://assets/data/gamedata.json` — если файлы переложить,
игра не соберётся.

⚠️ Не запускай `project.godot` двойным щелчком — этот файл открывается только через
редактор Godot (следующий шаг).

## Шаг 4. Импортировать проект в Godot

1. Запусти Godot — откроется менеджер проектов.
2. Нажми **Import** (Импорт).
3. Кнопка **Browse** → выбери `CRYPTO_HACK_godot\project.godot`.
4. **Import & Edit**.

Godot 5–15 секунд импортирует шрифты и данные. В этот момент ничего не трогай, внизу
будет бежать полоска прогресса.

## Шаг 5. Запустить

Нажми **F5** (или кнопку ▶ в правом верхнем углу).

Что должно произойти:

1. Главное меню с заголовком **CRYPTO_HACK** и цитатой внизу.
2. Кнопка **НАЧАТЬ ИГРУ** → строки загрузки BIOS → рабочий стол.
3. Сам откроется хак-терминал с первой миссией. В правом верхнем углу видно `$150` и `ур. 1`.

В первой миссии напиши `scan()` и нажми **▶ ЗАПУСТИТЬ** — в консоли появится результат
сканирования и «ВЗЛОМ УСПЕШЕН».

## Если что-то не так

| Симптом | Причина и решение |
| --- | --- |
| В консоли `Parse Error` | Версия Godot старше 4.3 — поставь свежую (4.4 / 4.5). |
| `Failed to load resource` / `Cannot open file` | Файлы лежат не рядом с `project.godot` или структура папок изменена — распакуй архив заново как есть. |
| Ошибок нет, но экран чёрный | Идёт импорт шрифтов, подожди пару секунд. Если долго — **Project → Reload Current Project**. |
| Godot предлагает «Convert project to a newer version» | Соглашайся, это обновление формата проекта. |
| `Import` не видит `project.godot` | В диалоге выбора включи показ всех файлов, либо перетащи `project.godot` прямо в окно менеджера проектов. |
