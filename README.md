# CRYPTO_HACK · NeonOS (Unity-версия)

Симулятор хакера на русском языке: пишешь настоящий код на Python, взламываешь
цели, ставишь майнеры, торгуешь криптой, учишься в школе Python и качаешь
апгрейды на чёрном рынке. Интерфейс — неоновая «хакерская ОС» NeonOS.

**Версия:** 1.0.3 (Unity-порт веб-версии; логика сверена с Godot-версией 1.0.2)
**Движок:** Unity 2022.3 LTS или Unity 6, uGUI, **весь интерфейс построен из C#-кода** — префабов нет
**Платформы:** Windows / Linux / macOS (запуск в редакторе или своя сборка)

➡️ **Установка и первый запуск — пошагово в файле [INSTALL.md](INSTALL.md).**

---

## Быстрый старт

1. Скачай репозиторий: кнопка **Code → Download ZIP** (или архив
   `CRYPTO_HACK_unity.zip` из корня) и распакуй в путь без пробелов и русских букв.
2. Unity Hub → **Add project from disk** → выбери папку, где лежат `Assets` и
   `ProjectSettings` → **Open**.
3. Дождись импорта и нажми **▶ Play**. Сцену создавать не нужно — игра
   стартует из пустой сцены сама.

## Что есть в игре

* **8 миссий-взломов** — от «Первого скана» до «Бесконечного майнинга»:
  переменные, циклы, условия, списки, свои функции. У каждой цели брифинг,
  теория, подсказки и готовое решение (без штрафа).
* **Реальный Python или симулятор** — код можно выполнять настоящим `python3`
  (с игровыми заглушками `scan/connect/brute/bypass/decrypt/extract/drain`),
  а можно встроенным симулятором с проверкой обязательных конструкций.
* **Майнинг-ферма** — взломанные компьютеры приносят крипту каждую секунду,
  даже при закрытом окне.
* **Биржа DARKEX** — 4 монеты (₿ BTC, Ξ ETH, ɱ XMR, ◎ SOL), живые курсы каждые
  2.5 секунды, график, комиссия, которую снижает стелс-модуль.
* **Чёрный рынок** — 4 апгрейда по 4–5 уровней: скорость взлома, эффективность
  майнеров, библиотека кода, стелс.
* **Школа Python** — 5 уроков с теорией и мини-тестом (+XP и стипендия).
* **Файлы** — виртуальная файловая система: твои эксплойты, кошельки, логи майнеров.
* **Профиль** — уровень, капитал, статистика и 8 достижений.
* **Сохранения** — автосейв в JSON, кнопка сброса прогресса.

Плюс «системные» радости: загрузка BIOS со звуком, матричный дождь, глитч-заголовок,
перетаскиваемые окна, панель задач, тосты и модалка повышения уровня. Все звуки
синтезируются кодом — внешних аудиофайлов в проекте нет.

## Технические решения

| Решение | Почему так |
|---|---|
| UI целиком кодом (uGUI), без префабов и сцен | проект открывается и запускается без ручной настройки, всё видно в диффах |
| Свой роутер кликов вместо `EventSystem` / `Button` / `InputField` | не зависит от настройки *Active Input Handling*, порядок кликов задаётся слоями, меньше ломких ассетов |
| `UiInput` поддерживает и старый Input Manager, и новый Input System | работает и в 2022.3, и в Unity 6 без правок настроек проекта |
| Шрифт один — `DejaVuSansMono` (+ `JetBrainsMono` для символа ₿) | без внешних зависимостей и с полной кириллицей |
| Контент в `Assets/Resources/gamedata.json` | один файл данных, легко править миссии и уроки |
| `GameBoot` запускается через `RuntimeInitializeOnLoadMethod` | игра стартует в любой сцене, включая пустую |

## Структура репозитория

```
Assets/…      исходники игры (C#), контент, шрифты, редакторное меню
Packages/     manifest.json с зависимостями
ProjectSettings/  версия редактора проекта (2022.3.0f1)
tools/        check_cs.py — линтер C# без Unity (tree-sitter)
INSTALL.md    пошаговый гайд по установке и запуску
```

Полный разбор файлов — в разделе 10 файла [INSTALL.md](INSTALL.md).

## Проверка кода без Unity

```bash
pip install tree-sitter tree-sitter-c-sharp
python3 tools/check_cs.py Assets
```

Скрипт проверяет синтаксис всех `.cs`, обращения к членам собственных классов,
число аргументов у вызовов и объявленность полей. На текущем коде:
`файлов 25, ошибок синтаксиса 0, семантических замечаний 0`.
